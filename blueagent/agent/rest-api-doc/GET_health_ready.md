# GET /health/ready

## ENDPOINT & METHOD
`GET /health/ready`

## PURPOSE & CTFD CONTEXT
READINESS PROBE. VALIDATES DEEP BACKEND SUBSYSTEMS (SQLITE DATABASE CONNECTIVITY, INCUS CONTAINER ENGINE, LIFECYCLE WORKER).
USE CASE: CTFD PLUGIN READINESS CHECK BEFORE RUNNING BULK PROVISIONING / VERIFICATION.

## AUTHENTICATION
NONE. PUBLIC ENDPOINT.

## REQUEST
HEADERS: NONE.
PARAMS: NONE.
BODY: NONE.

## RESPONSE
STATUS: `200 OK`
CONTENT-TYPE: `application/json`
SCHEMA:
```json
{
  "status": "ready",
  "database": "connected",
  "lifecycle_worker": "running"
}
```
NOTE: IF DB DISCONNECTED, RETURNS `"status": "degraded"`, `"database": "unreachable"`.

## CTFD PLUGIN ACTION
IF `status != "ready"`, DISABLE CHALLENGE LAUNCH & DISPLAY ADMIN ALERT.
