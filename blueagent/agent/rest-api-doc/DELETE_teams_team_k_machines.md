# DELETE /teams/{team_k}/machines

## ENDPOINT & METHOD
`DELETE /teams/{team_k}/machines`

## PURPOSE & CTFD CONTEXT
TEARDOWN DEPLOYED CONTAINERS FOR TEAM:
STOPS AND DELETES LIVE CONTAINERS TIED TO SPECIFIC CHALLENGE OR ENTIRE TEAM.
KEEPS TEAM WIREGUARD VPN & BRIDGE INTACT (ONLY DESTROYS APPLICATION CONTAINERS).
USE CASE: ADMIN TEARDOWN CHALLENGE INSTANCE, CHALLENGE RESET/ROLLBACK, CLEANUP AFTER ROUND ENDS.

## AUTHENTICATION
REQUIRED: `Authorization: Bearer <token>` OR `X-CTFd-Token: <token>`.

## REQUEST
PATH PARAMETER:
- `team_k` (INT, REQUIRED, 0..254): TARGET TEAM INDEX.
HEADERS: `Content-Type: application/json`
BODY (OPTIONAL `ChallengeConfig`):
- IF BODY PROVIDED WITH `containers`, DELETES ONLY SPECIFIED CONTAINERS.
- IF BODY OMITTED OR NULL, TEARS DOWN ALL CONTAINERS FOR `team_k`.

## RESPONSE
STATUS: `204 No Content`
BODY: NONE.

## ERROR CODES & CTFD ACTION
- `404 Not Found`: TEAM NOT FOUND.
- `503 Service Unavailable`: TEAM RESOURCE BUSY / LOCKED -> RETRY.
- `500 Internal Server Error`: `TeardownError` -> INCUS CONTAINER ENGINE ERROR.
- `401 Unauthorized`: TOKEN INVALID.
