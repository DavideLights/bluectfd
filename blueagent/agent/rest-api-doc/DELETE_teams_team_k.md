# DELETE /teams/{team_k}

## ENDPOINT & METHOD
`DELETE /teams/{team_k}`

## PURPOSE & CTFD CONTEXT
ATOMIC COMPLETE TEARDOWN OF ALL TEAM RESOURCES:
1. DELETES ALL RUNNING CONTAINERS FOR TEAM ON INCUS.
2. TEARS DOWN WIREGUARD INTERFACE `wg-k`.
3. DESTROYS LINUX BRIDGE `br-team-k`.
4. FLUSHES NFTABLES RULES FOR `team_k`.
5. DELETES TEAM & PEER RECORDS FROM BLUEAGENT SQLITE DB.
USE CASE: ADMIN PURGES TEAM, COMPETITION RESET, TEAM DISQUALIFIED / DELETED IN CTFD.

## AUTHENTICATION
REQUIRED: `Authorization: Bearer <token>` OR `X-CTFd-Token: <token>`.

## REQUEST
PATH PARAMETER:
- `team_k` (INT, REQUIRED, 0..254): TARGET TEAM INDEX.
HEADERS: `Authorization: ...`
BODY: NONE.

## RESPONSE
STATUS: `204 No Content`
BODY: NONE.

## ERROR CODES & CTFD ACTION
- `503 Service Unavailable`: TEAM RESOURCE BUSY / LOCKED (E.G. ACTIVE VERIFICATION IN PROGRESS) -> WAIT & RETRY.
- `500 Internal Server Error`: PARTIAL TEARDOWN FAILURE -> INSPECT LOGS.
- `401 Unauthorized`: TOKEN INVALID.
