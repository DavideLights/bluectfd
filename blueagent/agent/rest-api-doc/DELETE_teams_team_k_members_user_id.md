# DELETE /teams/{team_k}/members/{user_id}

## ENDPOINT & METHOD
`DELETE /teams/{team_k}/members/{user_id}`

## PURPOSE & CTFD CONTEXT
REMOVE INDIVIDUAL MEMBER FROM WIREGUARD PEER LIST & RECLAIM IP ADDRESS:
1. REMOVES PEER PUBLIC KEY FROM KERNEL WG INTERFACE (`wg set wg-k peer <pubkey> remove`).
2. DELETES RECORD IN BLUEAGENT DATABASE.
3. RELEASES IP BACK TO POOL FOR TEAM `k` (ENABLES DYNAMIC HOLE-FILLING REUSE).
USE CASE: PLAYER REMOVED FROM TEAM IN CTFD, REVOKING COMPROMISED CLIENT VPN KEYS.

## AUTHENTICATION
REQUIRED: `Authorization: Bearer <token>` OR `X-CTFd-Token: <token>`.

## REQUEST
PATH PARAMETERS:
- `team_k` (INT, REQUIRED, 0..254): TARGET TEAM INDEX.
- `user_id` (STR, REQUIRED): CTFD USER ID OR MEMBER IDENTIFIER.
HEADERS: `Authorization: ...`
BODY: NONE.

## RESPONSE
STATUS: `204 No Content`
BODY: NONE.

## ERROR CODES
- `404 Not Found`: TEAM OR MEMBER NOT FOUND.
- `503 Service Unavailable`: TEAM WG LOCK BUSY -> RETRY.
- `401 Unauthorized`: TOKEN INVALID.
