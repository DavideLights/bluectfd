# PUT /images/{alias}

## ENDPOINT & METHOD
`PUT /images/{alias}`

## PURPOSE & CTFD CONTEXT
CREATE OR UPDATE DISTROBUILDER CONTAINER IMAGE SPECIFICATION UNDER TARGET ALIAS:
1. ACCEPTS RAW YAML DEFINITION OR COMPRESSED ARCHIVE (`.tar.gz` / `.zip`) WITH `definition.yaml` + CHALLENGE ARTIFACTS (`files/`, `overlay/`).
2. PARSES `definition.yaml` & COMPUTES SHA256 HASH.
3. CHECKS DATABASE:
   - IF HASH IDENTICAL & IMAGE ALREADY `ready` (AND `force=false`), RETURNS `200 OK` IDEMPOTENTLY.
   - IF NEW, HASH CHANGED, PREVIOUS STATE `failed`, OR `force=true`: SETS STATUS `building`, DISPATCHES ASYNC BUILD PIPELINE, AND RETURNS `202 Accepted`.
4. BACKGROUND BUILD PIPELINE:
   - UNPACKS BUILD CONTEXT ARCHIVE IF SUBMITTED.
   - PRE-BAKES `/etc/systemd/network` AND `/etc/network` DIRECTORIES INTO POST-FILES ACTIONS.
   - COMPILES UNIFIED IMAGE VIA `distrobuilder build-incus`, STREAMING LOGS TO `{image_build_dir}/{alias}.log`.
   - IMPORTS UNIFIED TARBALL INTO INCUS VIA CONSTANT-MEMORY 1MB STREAMING GENERATOR.
   - SETS INCUS ALIAS TO NEW FINGERPRINT AND PRUNES SUPERSEDED OLDER FINGERPRINTS.
   - SETS STATUS `ready` IN DATABASE.
USE CASE: CTFD ADMIN UPLOADS NEW CHALLENGE BASE IMAGE OR UPDATES EXISTING IMAGE SPECIFICATION.

## AUTHENTICATION
REQUIRED: `Authorization: Bearer <token>` OR `X-CTFd-Token: <token>`.

## REQUEST
PATH PARAMETER:
- `alias` (STR, REQUIRED): IMAGE ALIAS (REGEX `^[a-z0-9][a-z0-9-]{0,31}$`).
QUERY PARAMETERS:
- `force` (BOOL, OPTIONAL, DEFAULT `false`): FORCE REBUILD EVEN IF HASH MATCHES.
HEADERS: `Content-Type: multipart/form-data`
FORM DATA FIELDS:
- `file` (OR `definition`, FILE, REQUIRED): DISTROBUILDER YAML FILE (MAX 256KB) OR BUILD CONTEXT ARCHIVE (`.tar.gz`/`.zip`, MAX 100MB).

## RESPONSE
STATUS:
- `202 Accepted`: BUILD TRIGGERED IN BACKGROUND (PENDING).
- `200 OK`: IMAGE ALREADY BUILT AND READY (IDENTICAL SHA256).
CONTENT-TYPE: `application/json`
BODY SCHEMA (`ImageRecord`):
```json
{
  "alias": "alpine-3.20-nginx",
  "yaml_sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "yaml_text": "image:\n  description: Alpine 3.20...",
  "status": "building",
  "fingerprint": null,
  "error": null,
  "created_at": "2026-10-12T15:20:00Z",
  "updated_at": "2026-10-12T15:20:00Z"
}
```

## ERROR CODES & CTFD ACTION
- `413 Request Entity Too Large`: YAML FILE EXCEEDS 256KB OR ARCHIVE EXCEEDS 100MB.
- `422 Unprocessable Entity`: YAML SYNTAX INVALID, ARCHIVE MISSING `definition.yaml`, OR ALIAS FORMAT ILLEGAL.
- `409 Conflict`: IMAGE CURRENTLY BUILDING (`ImageStateConflictError`).
- `401 Unauthorized`: TOKEN INVALID.
