# DELETE /images/{alias}

## ENDPOINT & METHOD
`DELETE /images/{alias}`

## PURPOSE & CTFD CONTEXT
DELETE CONTAINER IMAGE ALIAS AND REMOVE IMAGE FROM INCUS STORAGE, LOGS, CONTEXT FILES, & DATABASE:
1. ENFORCES FOREIGN KEY SAFETY CHECK: IF ACTIVE RUNNING CONTAINERS CURRENTLY USE IMAGE, BLUEAGENT BLOCKS DELETION.
2. REMOVES IMAGE FROM INCUS ENGINE STORAGE POOL.
3. REMOVES BUILD LOG FILE AND ARCHIVE CONTEXT FROM DISK.
4. DELETES IMAGE RECORD FROM DATABASE.
USE CASE: ADMIN CLEANS UP OBSOLETE/UNUSED CHALLENGE IMAGES.

## AUTHENTICATION
REQUIRED: `Authorization: Bearer <token>` OR `X-CTFd-Token: <token>`.

## REQUEST
PATH PARAMETER:
- `alias` (STR, REQUIRED): TARGET IMAGE ALIAS.
HEADERS: `Authorization: ...`
BODY: NONE.

## RESPONSE
STATUS: `204 No Content`
BODY: NONE.

## ERROR CODES & CTFD ACTION
- `404 Not Found`: IMAGE ALIAS NOT FOUND IN CATALOG.
- `409 Conflict`: `ImageInUseConflictError` -> IMAGE CANNOT BE DELETED WHILE IN USE BY RUNNING CONTAINERS. CTFD MUST FIRST TEARDOWN CONTAINERS ON AFFECTED TEAMS.
- `401 Unauthorized`: TOKEN INVALID.
