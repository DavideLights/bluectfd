# GET /health

## ENDPOINT & METHOD
`GET /health`

## PURPOSE & CTFD CONTEXT
LIVENESS PROBE. VERIFIES BLUEAGENT REST SERVICE RUNNING & LISTENING.
USE CASE: CTFD PLUGIN STARTUP HEALTHCHECK, ADMIN DASHBOARD ONLINE BADGE.

## AUTHENTICATION
NONE. PUBLIC ENDPOINT.

## REQUEST
HEADERS: NONE REQUIRED.
PARAMS: NONE.
BODY: NONE.

## RESPONSE
STATUS: `200 OK`
CONTENT-TYPE: `application/json`
SCHEMA:
```json
{
  "status": "ok"
}
```

## ERROR HANDLING
- CONNECTION REFUSED / TIMEOUT -> BLUEAGENT SERVICE DOWN. CTFD PLUGIN SHOWS "BLUEAGENT OFFLINE" WARNING.
